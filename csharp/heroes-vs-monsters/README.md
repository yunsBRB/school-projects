# Heroes vs Monsters

Jeu de combat en console écrit en C#, réalisé pour travailler la programmation orientée objet : personnages, monstres, jets de dés et arène.

## Lancer

Prérequis : SDK .NET 10. Se placer dans `csharp/heroes-vs-monsters`.

```sh
dotnet run --project "src/HvM 2.0.csproj"
```

## Organisation

Les sources et le projet sont dans `src/`. Les sorties de compilation (`bin`, `obj`) sont ignorées. Le workflow compile le projet ; il ne valide pas encore les règles de combat.

## Historique

Ce dossier reprend la version auparavant nommée `HvM`. Les autres essais restent conservés dans les archives privées. Leurs différences ne sont pas fusionnées artificiellement avec cette version.
