## Travailler sur un projet

Entrer dans son dossier avant de lancer les commandes de son README. Il n’y a pas de build unique pour tout le dépôt.

Les tests automatisés couvrent MoonName et la compilation/démarrage de la médiathèque ; les projets C# sont compilés. Cela ne constitue pas une validation complète de tous les parcours.

[MIGRATION.json](MIGRATION.json) conserve la provenance des fichiers. Les anciennes variantes restent dans les archives privées.
